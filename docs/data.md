# Данные

Все таблицы — CSV в UTF-8; `.csv.gz` читается напрямую через `pandas.read_csv`.

## `data/evaluations.csv.gz` — оценки во время обучения

Одна строка — один эпизод оценки: 162 900 строк, 540 запусков.

| Столбец | Значение |
|---|---|
| `stage` | `pretrain` (мир A), `branch` (ветвь в мире B), `control` (Н, А→А), `extension` (Г+) |
| `condition` | условие, см. `configs/experiment.json` → `conditions` |
| `architecture` | `linear`, `mlp16`, `mlp64`, `mlp256` |
| `train_seed` | сид запуска: 11–55 (основная серия), 101–505 (повтор) |
| `world` | мир, в котором шла оценка (`A` или `B`) |
| `step` | шагов обучения от начала этапа. У ветвей 0 — модель мира A сразу после смены правил; у Г+ — 112 640…204 800, то есть от начала мира B |
| `eval_seed` | сид старта эпизода (10000–10029) |
| `episode_length` | длина эпизода, шаги (не больше 500) |
| `terminated`, `truncated` | 1 — агент погиб / 1 — достигнут лимит 500 шагов |
| `beneficial`, `harmful` | съедено полезных / вредных ресурсов за эпизод |
| `policy_sha256` | SHA-256 весов политики в этой точке (функция `state_hash`); по нему проверяется побитовое воспроизведение. У Г+ пусто: в исходной серии хеш не записывался |

У условия Б250 здесь только оценка при энергии 100, общая для всех условий.

## `data/baselines.csv` — простые стратегии

Случайные действия (`random`) и движение всё время влево (`fixed_left`) в обоих мирах, на тех же 30 стартах. По ним видно, что L ≈ 100 означает выживание на начальном запасе энергии без еды.

## `data/rollout_episodes.csv.gz` — поведение итоговых моделей

40 пар (архитектура, сид) × 8–9 итоговых моделей × 2 режима × 100 стартов (сиды 20000–20099) в мире B.

| Столбец | Значение |
|---|---|
| `model` | `pretrain` (модель после мира A, «А»), `baseline` (К), `scratch_B` (Н), сбросы, `head_reset_extended` (Г+) |
| `mode` | `deterministic` — наиболее вероятное действие; `stochastic` — действие выбирается случайно по распределению политики |
| `length`, `beneficial`, `harmful` | длина эпизода и съеденные ресурсы |
| `died` | 1 — агент погиб (иначе дошёл до 500 шагов) |
| `stuck` | 1 — погиб, а за последние 30 шагов побывал не более чем в 2 клетках и ничего не съел |
| `blocked_fraction` | доля ходов в стену |
| `swing_fraction` | доля ходов, после которых агент снова в клетке, где был два шага назад |

## `data/behaviour.csv` — показатели моделей

Одна строка — одна модель одного запуска и один вид измерения (`measurement`):
- `visited_deterministic`, `visited_stochastic` — доли посещённых состояний, где выбранное действие приближает только к новому полезному ресурсу (`new_only`), только к прежнему (`old_only`), к обоим (`both`) или ни к одному (`neither`); в сумме 1;
- `probe_final` — энтропия политики (доля от ln 4) и те же доли для наиболее вероятного действия на 2048 случайных состояниях `data/probe_states.npy`;
- `probe_after_reset` — то же для политики сразу после сброса (сброс применяется к модели мира A);
- `activations` — скрытые слои политики на общем наборе посещённых состояний (модели А, К, Н, Г того же запуска):
  - доля «спящих» нейронов (`dormant_max_layer`, максимум по слоям);
  - доля насыщенных нейронов Tanh (`saturated_max_layer`);
  - эффективный ранг последнего слоя (`srank_last`).

## Итоговые модели (архив в релизе)

`checkpoints/<условие>/<архитектура>_seed<сид>.zip` — итоговая модель каждого запуска в формате Stable-Baselines3. Для моделей мира A рядом лежит `*_rng_after_A.json` — состояние генераторов случайных чисел, с которого стартуют все ветви. Контрольные суммы — в `checkpoints/SHA256SUMS.json`.
